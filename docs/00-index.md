## תקציר חד-משפטי

מוצר web שמקבל ממבחני עבר פתורים (קבצי PDF) ומייצר דף נוסחאות מודפס, תוך זיהוי אוטומטי של סוגי שאלות ואיחוד כפילויות — תהליך שהמשתמשת ביצעה בעבר ידנית מול Claude, על פני מספר שיחות והעלאות קבצים חוזרות.

> כל סעיף המסומן "**נדרשת החלטה**" מחייב הכרעה של הצוות (או לפחות רישום החלטת-דחייה מודעת) לפני מסירת המסמך לסוכן הפיתוח.
